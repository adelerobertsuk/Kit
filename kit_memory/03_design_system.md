# Design System & UI/UX Principles

- **Aesthetic**: Minimal, editorial, tactile, Apple-inspired.
- **Palette**: Warm off-white/ivory canvases, charcoal/black typography, subtle natural accents (linen, travertine, warm wood tones).
- **Layout**: Generous whitespace, scannable hierarchies, quiet typography (SF Pro / modern clean sans-serif), zero visual clutter.
