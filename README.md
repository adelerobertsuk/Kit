# Kit

Adele’s walk tape. Talk. It writes the words down. That is the whole job today.

Not a Tesla. Not Grok living in an app. Grok reads the tapes in Cursor in the morning. Kit is how the road talks to this Mac.

Walks: Gemini app on the unlocked phone. Adele talks. Gemini summarises and saves into Studio. The Diane Gem is broken. Do not wait for it.

Kit on the Mac is the pretty skin. Racks Room tapes should look like Adele’s VHS stack (`Racks-Room-VHS-reference.png`): paper labels, marker titles, colour bars from smart sort. Play is reading the text. No audio files.

## One job

**Normal Cruise.** Cooper to Diane. Speech becomes text. Text becomes a tape in the Racks Room. No audio file. No cloud. No talk-back.

Auto Cruise and Pursuit Mode already exist in the Lovable skin. Leave them. Do not invent a fourth button.

## How to use it tonight

In this folder:

```sh
npm install
npm run dev
```

Safari or Chrome. Allow the mic. Leave it on **Normal Cruise**. Tap to talk. Stop. Open **Racks Room**. Play is reading the text.

Chrome/Safari speech-to-text is the engine. Firefox will not transcribe.

## Morning in Cursor
